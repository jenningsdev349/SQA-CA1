# Team Reflection

## Introduction


## Adam
I'm happy with how this assignment turned out. The project plan was followed by all team members which contributed to the consistent style and quality of work we produced. Pull Requests were done to a high standard, everyone made valuable insights in the comments on top of pointing out smaller errors within files. Writing my own article - Task Estimation - and contributing to the Code Reviews article was the easiest part of the assignment in my opinion. There was plenty of material online to source and the project plan was helpful in laying out the format articles followed. I took on the brunt of "admin" type work - setting up the repo, creating the project plan document, creating the article introductions document. This was difficult but I had support from the other contributors on these tasks so the workload was made easier. There were some small errors that occurred in the project, the three of us created branch names with slightly varying names for example. This was not a big deal but in a wider team context ideally branch names should all follow the exact same naming convention. Some comment chains that occurred could have also been handled in a more efficient way offline, which would have helped articles get merged faster and avoid some of the questions posed in comment form. We all followed a similar template for PRs but a more rigid template should have been laid out better in the project plan.
